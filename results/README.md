# Results

The figure notebook writes manuscript figures and supporting tables to
`figures/`. The release data ZIP includes these exports; Git tracks only this
README. Generated detection and discrimination data are under `data/`.
Within `figures/`, `statistics/` holds the reported comparison tables and
`suppfig5_population_recruitment_data/_data/` holds the source tables and
provenance for Supplementary Figure 5. Both are production figure inputs.

Local notebook verification files are written to `.local-archive/`. Longleaf
run receipts and validation are written to `logs/pipeline/`; neither is part
of the public data archive.
