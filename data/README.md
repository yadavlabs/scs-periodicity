# Population data layout

Small source inputs are tracked in Git: 35 paired COMSOL cutlines under
`comsol/`, source Slack time patterns and behavioral observations,
55 generated population time-pattern bundles, 420 population Ve bases, and the
reference index screen under `population/reference/`.

`time-patterns/slack/` contains the original input pattern exports;
`time-patterns/population/` contains the waveform bundles used for the 420-axon
simulation. The `detection/slack/` and `discrimination/slack/` directories hold
behavioral observations shared with the previous release.

The HPC workflow creates the large `detection/population/` response tables.
Feature engineering creates `features/population/`; the observer and figure
stages write their outputs under `results/population/`. These production
outputs belong in the versioned release-data archive generated by
`src/package_data.py`, not in Git. The packager requires complete outputs and
selects population paths explicitly.

Paths inside the tracked population manifests are repository-relative so the
inputs work after extraction in a new checkout.
